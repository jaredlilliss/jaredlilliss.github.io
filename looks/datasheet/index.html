6.0App

Applications information

6.1 Field service

Point-of-sale and payment terminals, Windows machines, structured cabling and cameras. The customers are venues and small businesses around Sydney. Attendance is usually the same day and usually on site. The same work trades as Lilliss IT and covers Sydney and regional NSW.

6.2 Collection

The Aussie Health Utility reads how many people are waiting in each NSW emergency department that publishes a live count, every fifteen minutes, and appends the reading to a PostgreSQL series that is never rewritten. Fifty-nine departments publish a live count; there are 176 in NSW.

The upstream feed publishes the current moment only and keeps no history. A reading not taken at the time is gone for good. Collection started on 20 July 2026 and more than 120,000 readings have been appended since. It ran on a laptop first, which slept, so the early weeks have gaps. Since 23 August 2026 it has run on a small Melbourne server and nothing after that is missing. A database dump is taken at 03:30 Melbourne time each night and copied off the machine.

No personal or health information is collected, because the schema has no fields for it.

6.3 Documents

Every page on this site is a single HTML file with no build step and no framework. There are zero external requests: the fonts are self-hosted and nothing is loaded from another host. Once loaded, a page works with the network cable pulled.

Card2of 7

Aussie Health Utility

Collector and public record · New South Wales · 2026–

Collecting
since
20 Jul 2026

A collector reads how many people are waiting in each New South Wales emergency department that publishes a live count. It reads every fifteen minutes and appends the reading to a PostgreSQL series that is never rewritten.

Fifty-nine departments publish a live count. New South Wales has 176 in total, so this is not every department.

No personal or health information is collected. That is not a policy on top of the schema; the schema has no fields for it.

The upstream feed publishes the current moment only and keeps no history. A reading not taken at the time is gone for good.

It ran on a laptop first, and the laptop slept, so the early weeks have gaps. Since 23 August 2026 it has run on a small Melbourne server and nothing after that is missing. A database dump is taken at 03:30 Melbourne time each night and copied off the machine.

The Span

Design concept · 1975 to 2117 on one screen

Every
line
sourced

One screen holds 1975 to 2117: the space programme of the United Arab Emirates drawn as a single span you travel by dragging.

Fifteen milestones. Each one is a drawn line that means its own event rather than an icon off a shelf, and each names the source that establishes it. Thirteen link straight to the government page they came from. Nothing on it is estimated.

It is deep-linkable to any year, it can be worked from the keyboard, and with scripting switched off it reads as a plain sourced list. Unsolicited, and no affiliation.

The drawer itself

Physical description of the site

No

Every page on this site is a single HTML file. No build step and no framework.

Zero external requests. The fonts are held here and nothing is loaded from another host, so a page keeps working with the network cable pulled once it has loaded. The one exception on this card is the live slip above, which reads a file from this same site and is written to be complete without it.

This drawer is one of several looks for the same content. The band at the top of the page leads back to the rest.

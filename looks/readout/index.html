04

Collector

Aussie Health Utility

The collector reads how many people are waiting in each NSW emergency department that publishes a live count. It runs every fifteen minutes and appends each reading to a PostgreSQL series. Rows are never rewritten.

The upstream feed publishes the current moment only and keeps no history. A reading not taken at the time is gone for good.

The laptop slept, which is why the early weeks have gaps. Since 23 August 2026 the collector has run on a small Melbourne server and nothing after that date is missing. The database dump is taken at 03:30 Melbourne time each night and copied off the machine. No personal or health information is collected, because the schema has no fields for it. The repository above is a public mirror; the working repository stays private.

This page

How it is built and what it does when the data is missing

Every page on this site is a single HTML file. There is no build step and no framework. The fonts are served from this site, and nothing is loaded from another host, so a page keeps working once it has loaded and the network is pulled.

The live cells above ship carrying the fixed record and are overwritten only after the reading file parses. When it does not, the fixed record stands in their place.

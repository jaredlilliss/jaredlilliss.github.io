Level 5

The server

A small Melbourne machine that has been awake since 23 August. It takes a reading every fifteen minutes, dumps its database at 03:30 Melbourne time and copies the dump off itself.

Before that it ran on a laptop, which slept — so the early weeks have gaps, and the record shows them.

Level 6

The row

59 departments15 min120,000+ readings

Each reading is appended to a series that is never rewritten. The feed publishes the current moment only and keeps no history, so a reading not taken at the time is gone for good. The figure is people waiting, never a waiting time — there is no minutes field. No personal or health information is collected, because the schema has no fields for it.

Level 7
